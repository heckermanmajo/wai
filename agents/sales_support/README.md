# sales_support

**Typ:** Agent
**Status:** Skeleton

## Zweck
Vertriebs-Unterstützung: Leads anreichern, Mail-Entwürfe, Angebots-Bausteine, Follow-up-Tracking.

## Verantwortlichkeiten
- Lead-Daten konsolidieren (intern + öffentliche Quellen)
- Mail-/Angebots-Drafts erstellen
- Follow-up-Reminder setzen
- Pipeline-Reports

## Genutzte Tools
- `tools/websearch` — Lead-Recherche
- `tools/database_management`
- `tools/tasks` — Follow-ups
- `tools/embeddings_search` — ähnliche Deals aus Historie

## DB-Zugriffe
- Tenant DB: `Lead`, `Task`, `Reminder`, `Message`
